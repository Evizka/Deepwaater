# Deepwaater

Мод для **Minecraft 1.21.1 (NeoForge)** с биомом **«Глубокое болото» (`deepwaater:deep_bog`)**.

## Что добавляет мод

- **Сеноты** (`deepwaater:cenote`) — глубокие круглые ямы (16–40 блоков) до грунтовой воды.
  Стенки покрыты **болотным мхом**, на дне **болотный ил**, на стенах висят лианы.
  Соседние сеноты соединены **подземными туннелями**, поэтому между ними получается пещерная система.
- **Болотные деревья** (`deepwaater:swamp_tree`) — высокие деревья (22–34 блока) с толстым стволом 2×2,
  широкой кроной и длинными ветвями. Их **корни уходят глубоко в землю**: стержневой корень
  8–15 блоков вниз и несколько боковых корней, которые опускаются в грунт.
- **Собственные блоки** (вместо ванильных):
  - `deepwaater:deep_bog_log` — бревно глубокого болота;
  - `deepwaater:deep_bog_leaves` — листва глубокого болота;
  - `deepwaater:deep_bog_roots` — корни болота;
  - `deepwaater:bog_mud` — болотный ил;
  - `deepwaater:bog_moss` — болотный мох.
  Все они лежат во вкладке **Deepwaater** творческого режима.
- **Биом** — тёплое влажное болото у побережья. Вода тёмно-зелёная, трава с болотным оттенком.
  Мобы: зомби, пауки, слаймы, ведьмы, лягушки, летучие мыши, кальмары.

Биом подключается к миру через библиотеку **TerraBlender** (см. `DeepBogRegion.java`).
Вода и лианы пока ванильные.

## Структура проекта

```
src/main/java/com/evizka/deepwaater/
  DeepWaater.java                 — точка входа мода
  block/ModBlocks.java            — собственные блоки
  item/ModItems.java              — предметы-блоки и вкладка творческого режима
  worldgen/
    ModBiomes.java                — ключ биома
    ModFeatures.java              — регистрация фич (сеноты, деревья)
    DeepBogRegion.java            — где на карте климата появляется биом (TerraBlender)
    CenoteFeature.java            — сеноты и пещерная сеть между ними
    SwampTreeFeature.java         — болотные деревья и их корни
    WorldGenUtil.java             — общие помощники (запись блоков в чанк, хэш-шум)
src/main/resources/
  data/deepwaater/worldgen/
    biome/deep_bog.json           — сам биом: цвета, мобы, пещеры, список фич
    configured_feature/           — параметры фич (размеры, высота, блоки, шансы туннелей)
    placed_feature/               — правила размещения
  data/deepwaater/loot_table/blocks/ — что выпадает при добыче блоков
  assets/deepwaater/
    blockstates/, models/         — модели блоков и предметов
    textures/block/               — текстуры (генерируются скриптом, см. ниже)
    lang/                         — названия (en_us, ru_ru)
tools/
  generate_textures.py            — генерация 16×16 текстур блоков (только стандартный Python)
  smoke_test_server.py            — проверка на запущенном сервере (используется в CI)
```

## Сборка и запуск

Нужен **JDK 21**. Gradle подтянется из wrapper.

```bash
./gradlew runClient     # запустить Minecraft с модом (Windows: gradlew.bat runClient)
./gradlew build         # собрать jar в build/libs/
```

Для игры с готовым jar нужны **NeoForge 21.1.x** и **TerraBlender 1.21.1-4.1.0.8** в папке `mods`.

Готовый jar можно взять из последнего запуска GitHub Actions (артефакт `deepwaater-jar`) или из релизов.

## Как настроить генерацию

- Размер и глубина сенотов, шанс появления, шанс туннеля и его радиус:
  `configured_feature/cenote.json` (`radius`, `depth`, `water_fraction`, `chance`, `link_chance`, `tunnel_radius`).
- Высота и толщина деревьев: `configured_feature/swamp_tree.json`.
- Где появляется биом на карте: `DeepBogRegion.java` и вес региона в `DeepWaater.java`.

## Текстуры

Текстуры — простые процедурные 16×16. Перегенерировать:

```bash
python3 tools/generate_textures.py
```

## Проверки

GitHub Actions на каждый пуш:
1. собирает мод (`./gradlew build`);
2. проверяет содержимое jar и JSON-данные;
3. запускает выделенный сервер с модом и через RCON ставит дерево и сеноты командой `place feature`,
   проверяет, что блоки появились, и что биом находится командой `locate biome`.

## Выпуск новой версии

Каждое изменение мода выходит отдельной версией в **Releases**:

1. Поднять `mod_version` в `gradle.properties` (например, `0.1.2` → `0.1.3`).
2. Закоммитить и запушить ветку. GitHub Actions должен пройти зелёным.
3. Создать релиз с тегом `vX.Y.Z` на этом коммите. Workflow сам соберёт jar и прикрепит
   `deepwaater-X.Y.Z.jar` к релизу.
4. В описании релиза написать, что изменилось.

## Статус

Версии `0.1.x` проверены тем, что фичи выполняются без ошибок и ставят блоки, но их внешний вид
в мире ещё не осмотрен в игре — это следующий шаг.

Идеи дальше: собственные вода и лианы, предметы и рецепты для блоков, мобы, туман над водой.
